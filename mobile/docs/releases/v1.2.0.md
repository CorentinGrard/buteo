Buteo in French, the task built on the map with an area task's
targets, the task's rules and zone shapes, and a map in Buteo's
colours.

> **A backup instrument.** Buteo is no certified instrument: never
> use it as your only source for navigation, airspace or traffic.
> It is not made by the XCSoar project; report its problems in this
> repository's issues.

## What is new

- Buteo speaks the phone's language. French is complete; other
  languages get XCSoar's translations where the words are XCSoar's,
  English for the rest. The spoken callouts stay in English
- On Android 13 or newer, Buteo can have a language of its own:
  Settings → Apps → Buteo → Language (English or French)
- Build the task on the map: Task → Edit → On the map. A tap adds the
  waypoint under the finger, a point's chip sizes its zone or removes
  the point, and Done makes the last point the finish
- An area task's targets: Task → Targets shows each area on the map.
  A tap inside puts the target there; Distance and Radial move it in
  steps; Optimized lets XCSoar move it to finish at the minimum time
- The task's rules (Task → Edit → Rules): start gate open and close
  times, maximum start speed and height, minimum finish height (AGL or
  MSL), FAI start and finish rules, PEV wait and window
- Zone shapes: a sector's radials, a sector's or keyhole's angle, an
  annular sector's or keyhole's inner radius
- Other starts, listed under the start point
- The map in Buteo's colours: landables green when reachable, orange
  when not; the task in magenta; airspace in softer tones, a thin
  outline with a light band inside. An airspace with a warning is
  filled orange (ahead) or red (inside) until you acknowledge it
- The task and contest maps (Analysis, the flight summary, a flight's
  page) show the terrain behind them, faded, as the map does

## Fixed

- A task set before a flight was lost when Android restarted Buteo,
  even in flight; it now comes back
- Quick taps on the task editor's − and + buttons were lost: each tap
  now counts

## Install

Android 8 or newer, on a 64-bit ARM phone. It updates 1.1.0 and 1.0.0
in place and keeps your files.

- With [Obtainium](https://github.com/ImranR98/Obtainium), which
  keeps Buteo up to date: see the
  [README](https://github.com/CorentinGrard/buteo#readme)
- By hand: download `buteo-1.2.0.apk` below on the phone, open it, and
  let the browser install apps when Android asks
